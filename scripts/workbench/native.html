Files to include and upload limits

A ZIP must contain one board and matching .kicad_pro at its root, matching .kicad_dru, .dc.json and .routing.json if used, plus fp-lib-table and referenced ${KIPRJMOD}/ footprint libraries. These assets keep the library checks available.

Board, project, rules, JSON and footprint files use UTF-8. Recognized LICENSE and NOTICE files retain their original bytes. ZIP limits: 16 MB compressed, 20 MB unpacked, 512 entries. Loose files: 20 MB total; request: 24 MB. Include optional rule and profile files with the same board filename.

Create needs a circuit and exact footprints; a KiCad board keeps its supplied placement. Finish repairs open connections. Improve compares changes against your original board.

How changes are accepted

Finish preserves protected copper and already-connected source contacts while repairing open connections under the original rules. Improve keeps the original as fallback and accepts shorter copper, fewer vias, or a repaired supplied voltage limit with no regression in the measured checks. Lock critical copper or list protected nets before improving. These checks cover declared rules and scenarios, not every aspect of electrical performance.

Supported inputs and check limits

New-design JSON supplies the circuit and exact footprints. Automatic initial placement currently supports rectangular boards. Native KiCad inputs retain their existing placement. Explicit plane definitions can add rectangular filled copper with solid pad connections. This does not infer circuits or choose parts. Differential-pair coupling, timing and impedance are not solved by this router. Optional DC profiles check supplied loads and voltage limits using trace and through-via resistance. Explicit return terminals can include ground loss; filled planes require an explicit mesh and a refinement check. Blind/buried vias are unsupported. Failing supply-voltage limits trigger clearance-limited widening of eligible supply traces, up to 2 mm. Locked and protected nets stay fixed. An improvement must preserve every modeled load voltage and not increase total resistive loss. Optional RC current-hold events check explicit effective capacitance, ESR, load steps and voltage envelopes with time and mesh refinement. Accepted improvements cannot worsen any declared RC voltage envelope. This passive model does not verify a regulator control loop, inductance or switching. Optional reference-plane rules guide routing over adjacent connected copper and check the full trace width plus a supplied margin. This currently supports single-layer signals without vias. Terminal-path limits, matching groups, minimum widths, via counts and allowed layers can also be checked. These are explicit bounds, not automatic timing or impedance qualification. Original project rules are checked; failures remain blocked.

Embedded footprints stay intact. Missing external libraries are reported by KiCad. A project ZIP carries its local footprint libraries; configured global libraries remain a local KiCad requirement. The CLI can be used for larger projects. No board is physically validated.
