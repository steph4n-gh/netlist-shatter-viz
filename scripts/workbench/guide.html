2. Read the checks

The result’s full review identifies remaining connections, enabled native findings, supplied profile checks and source preservation. A legal candidate path is not a completed board.

When checks fail

Inspect the retained candidate and findings. Failed or incomplete attempts are excluded from passing engineering downloads. A timeout does not prove that a physical route is impossible.

When checks pass

Download the files for that exact result. Read READ_FIRST.md and HANDOFF.json for file roles, checked scope and qualification holds.

Before building hardware

Review part pin functions, footprints, electrical requirements and assembly conventions. Native connectivity and CAM checks do not establish firmware operation, thermal behavior or manufacturing release.

3. Keep project assets together

A project ZIP contains one board and matching project/profiles at its root, plus fp-lib-table and referenced local footprint libraries. Library URIs must use ${KIPRJMOD}/ paths within the project. Preserve source license and notice files. The file picker explains size and encoding limits.

The source alpha includes runnable examples rather than historical board-manufacturing archives. New jobs write their own reports and, when required checks pass, engineering files into the local build/ directory.
