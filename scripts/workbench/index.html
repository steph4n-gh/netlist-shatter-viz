Checks, limits and source changes

Placement minimizes half-perimeter wire length (HPWL), an estimate—not actual routed length. Selected critical groups retain their relative geometry; placement issues are shown before routing. Routing uses the supported stock Freerouting JAR with automatic neckdown and fanout disabled, followed by bounded geometry repair. KiCad independently checks connectivity and design rules. Native copper/mask/drill output is compared against KiCad. These checks do not prove power integrity, signal integrity, firmware behavior or physical hardware operation.

The TCA9548A experiment is adapted from Adafruit's CC BY-SA 3.0 design. Copper solder jumpers are replaced by 0805 0R or DNP links; all 72 connected terminals are retained. Original connectors and mounting holes are fixed in this model. This model changes the upstream routing rules and source components. The source release includes the Adafruit attribution and original license. The original ground pours and artwork are not reused. This derivative has not been physically tested.
